# Welcome, كرم رشيد توفيق

**Here you can upload your tasks.**

This folder belongs to you. Everything you submit during the program goes here, and nowhere else.

## How to upload a task

1. Make sure you are inside this folder. The path at the top of the page must end with `karam_rasheed_tawfeeq`.
2. Click the green button `Add file`, then `Upload files`.
3. Drag your solution file into the page, or click `choose your files` and pick it.
4. Write a short message in the box at the bottom, such as `temperature converter solution`.
5. Click `Commit changes`.

That is the whole process. Your submission time is the moment you click that last button.

## Name the file after the task

The file name must be the task name, written exactly as the task folder is written in `tasks`, followed by `.dart`.

| Task | File you upload |
|------|-----------------|
| Temperature Converter | `temperature_converter.dart` |
| Grade Classifier | `grade_classifier.dart` |
| Bill Splitter | `bill_splitter.dart` |

So after three submissions, this folder looks like this:

```
karam_rasheed_tawfeeq/
  README.md
  temperature_converter.dart
  grade_classifier.dart
  bill_splitter.dart
```

Do not create folders inside here, and do not rename the file to anything else. When the instructor opens your folder, the file names alone tell him which tasks you finished.

## If you need to fix a submission

Upload the corrected file with the same name. It replaces the old one and both versions stay in the history. You may do this as many times as you want before the deadline.

## If you prefer to paste the code

Click `Add file`, then `Create new file`, type the file name such as `temperature_converter.dart`, paste your code, then `Commit changes`.

## Rules

1. Do not upload into a folder that carries someone else's name.
2. Do not upload zip files, screenshots, or generated folders such as `build`.
3. Do not delete this README.

The task descriptions are in the `tasks` folder at the top of the repository. If something goes wrong, read `docs/faq.md` or ask in the session.
