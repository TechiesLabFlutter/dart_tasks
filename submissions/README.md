# Submissions

Each participant owns one folder here, carrying their name. The folders already exist. Do not create new ones.

Inside your folder, one file per task, named exactly after the task folder in `tasks`, ending with `.dart`.

```
submissions/
  saja_mohammed/
    README.md
    temperature_converter.dart
    grade_classifier.dart
    bill_splitter.dart
```

Open your own folder and read the README inside it. It explains the upload in five steps.

Do not open, edit, or delete anything inside a folder that carries another participant's name.

If your folder is missing, or your name is written incorrectly, tell the instructor and it will be fixed.
