# Techies Lab, Dart Tasks

This repository holds the tasks of the training program and the work submitted by the participants.

Every participant already has a folder inside `submissions`, carrying their name. All of your work for the whole program goes inside that one folder.

## Repository map

```
tasks/                     the description of every task
  temperature_converter/README.md
  grade_classifier/README.md
  bill_splitter/README.md

submissions/               your work
  your_name/
    README.md              how to upload, written for you
    temperature_converter.dart
    grade_classifier.dart

docs/                      how to use this repository
```

## What you do

1. Read the task description inside `tasks/<task_name>/README.md`.
2. Write the solution on your own computer.
3. Open your own folder inside `submissions`, click `Add file`, then `Upload files`.
4. The file you upload must be named after the task, for example `temperature_converter.dart`.

No folders are created by you. One file per task, named after the task. When the instructor opens your folder, the file names tell him exactly what you submitted.

Full instructions are inside your own folder, and also in [docs/how_to_upload.md](docs/how_to_upload.md).
The rules your submission must follow are in [docs/submission_rules.md](docs/submission_rules.md).
Common problems and their solutions are in [docs/faq.md](docs/faq.md).

## How your work is evaluated

The instructor opens your folder, reads your code, and records a score in the program evaluation sheet.

The criteria are the same for every task and they are written at the bottom of each task description. In short: does it work, is it organised, is it readable, and can you explain it.

The submission date is the date of your upload. GitHub records it automatically, so upload before the deadline written in the task description.

## Important

This repository is public. Anyone can read it, including future employers. Treat it as part of your portfolio and keep it clean.

Do not upload passwords, API keys, personal documents, or any file that is not part of a task.
