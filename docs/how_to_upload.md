# How to upload your work

You do not need to install Git. Everything below happens on the GitHub website.

## Before your first upload

1. Create a GitHub account at github.com if you do not have one.
2. Send your username to the instructor.
3. You will receive an invitation by email. Open it and click the button that accepts the invitation. Until you accept it, you cannot upload anything.

## Find your folder

1. Open the repository page.
2. Click the `submissions` folder.
3. Click the folder that carries your name.

The folder is already there and it already contains a README written for you. You never create a folder.

## Upload a task

1. Click the green button `Add file`, then `Upload files`.
2. Drag your solution file into the page.
3. Look at the path shown at the top of the page. It must end with your own name.
4. Write a short message in the box at the bottom, such as `temperature converter solution`.
5. Click `Commit changes`.

Your work is now submitted. The time of that click is your submission time.

## Name the file after the task

The file name is the task name, spelled exactly as the task folder is spelled inside `tasks`, ending with `.dart`.

| Task folder in `tasks` | File you upload |
|------------------------|-----------------|
| `temperature_converter` | `temperature_converter.dart` |
| `grade_classifier` | `grade_classifier.dart` |
| `bill_splitter` | `bill_splitter.dart` |

Do not name it `main.dart`, `task1.dart`, or `solution.dart`. Every participant would then have three files with the same name and nobody could tell which task is which.

## Pasting code instead of uploading a file

If your code is short and it is easier to paste it:

1. Inside your folder, click `Add file`, then `Create new file`.
2. Type the file name, for example `grade_classifier.dart`.
3. Paste the code.
4. Click `Commit changes`.

## Fixing or improving a submission

Upload the corrected file with the same name. GitHub replaces the content and keeps both versions in the history. You may do this as many times as you want.

To edit a file directly, open it, click the pencil icon, change the text, then click `Commit changes`.

## Later in the program

When the tasks become full Flutter projects instead of a single file, the instructions change and you will be shown the new way in the session. For now, one file per task.
