# Frequently asked questions

## I do not see the Add file button

You are not signed in, or you have not accepted the invitation yet. Sign in, open the invitation email again, and accept it.

## I cannot find my folder

Open `submissions` and look for your name. The folders are sorted alphabetically by the Latin spelling of the name.

If it is genuinely not there, or the spelling is wrong, tell the instructor. Do not create a folder for yourself.

## What do I name the file

The task name, then `.dart`. For example `temperature_converter.dart`. Never `main.dart`.

## I uploaded into the wrong folder

Open the file you uploaded, click the three dots at the top right, choose `Delete file`, then commit. Upload it again in the correct place.

Nothing is lost by doing this, and it is not a mistake anyone will hold against you.

## I uploaded the wrong version of the file

Upload the correct file with the same name. GitHub replaces the content and keeps both versions in the history.

## My upload failed or the page froze

The usual cause is a folder such as `build` or `.dart_tool` being included by accident. These contain thousands of generated files. Upload the single `.dart` file instead.

## Can I upload a zip file

No. The instructor has to read your code inside the browser. A zip cannot be read there.

## Can I upload after the deadline

Yes, and you should. A late submission is still evaluated. The score reflects the delay, but an empty folder is worse.

## Can I see the work of other participants

Yes, and reading other people's code is useful. Copying it is not accepted, and it is easy to detect because every upload carries a name and a timestamp.

## I want to use Git from the terminal instead of the website

You are welcome to. The repository address is on the repository page under the green `Code` button. Ask the instructor if you want a short walkthrough during a session.

## Something else is broken

Bring it to the next session, or message the instructor with a screenshot of the page you are stuck on. Do not spend an hour fighting it alone.
